# Release notes: 0.2.0

Prepared for the upcoming `v0.2.0` release; not yet published.

This release adds bundled TOML and XML formatting, updates formatting defaults,
and makes the shared configuration independent of a build step and the caller's
working directory. It includes compatibility changes from `0.1.12`.

## Compatibility and migration

- Requires Node.js **22.12.0 or newer** and Prettier **>=3.9.8 <4**.
- Optional plugin ranges are now explicit: Astro **>=0.14.1 <0.15**, Svelte
  **>=4.1.1 <5**, and Tailwind **>=0.8.1 <1**. Astro 1.x is excluded because its
  AST is incompatible with class sorting in the tested Tailwind plugin 0.8.1.
- Continue importing `@cravingmaker/prettier-config` or referencing it in the
  `prettier` field of `package.json`. The package now ships `index.mjs` and
  `index.d.ts`; consumers should use the package entrypoint, not `dist/` paths.
- After upgrading, run Prettier and review the formatting diff. JSX/TSX
  attributes now use double quotes by default, Svelte attributes can use
  shorthand, and JavaScript code fences in Markdown inherit single quotes and
  Prettier's trailing-comma default.

## Formatting support

- Bundles `prettier-plugin-toml@3.0.2` and `@prettier/plugin-xml@3.4.2`; no
  separate consumer installation is required for either formatter.
- JSON/JSONC/JSON5, YAML/YML, TOML, and `.xml` files use a 100-column print width
  and spaces with the base two-column indentation setting. Markdown and MDX
  use 80 columns and spaces; the base code configuration remains at 120 columns
  with tabs.
- JSON formats use double quotes and no trailing commas. YAML prefers double
  quotes where quoting is needed. TOML prefers double-quoted keys and strings
  while preserving literal strings where needed, and retains key order.
- XML uses double-quoted attributes, preserves attribute order, and inherits
  one attribute per line. Its `preserve` whitespace mode retains text whitespace
  while formatting structural markup. Use `xmlWhitespaceSensitivity: 'strict'`
  in an XML override when all inter-element whitespace is significant.
- A passing TOML formatting check does not guarantee valid TOML; use a separate
  parser or validator when validation is required.

## Reliability

- Resolves plugins relative to the installed configuration, including when
  Prettier runs from a different working directory.
- Detects installed optional plugins without requiring unrelated framework
  packages just for detection. Missing plugins are skipped; broken installed
  plugins and unexpected resolution errors are reported. Tailwind remains last.
- Publishes the runtime configuration directly, with a corrected public
  TypeScript declaration entrypoint. TypeScript remains a development tool.
- Adds snapshot and idempotence coverage, all eight optional-plugin combinations,
  and packed-package tests, including a real npm-installed consumer and public
  TypeScript imports. CI also exercises consumers on Node.js 22.12.0.
