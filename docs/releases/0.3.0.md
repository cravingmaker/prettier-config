# Release notes: 0.3.0

Released: 2026-10-06.

This release uses Prettier and plugin defaults for formatting while retaining
`singleAttributePerLine: true` and the JavaScript/TypeScript Oxc parsers. It also
includes the MIT `LICENSE` file in the npm package.

## Formatting changes from 0.2.0

These defaults apply when the consumer has no overriding Prettier options or
EditorConfig settings. `printWidth` is a wrapping preference, not a hard limit;
plugins such as the package.json formatter can apply their own width behavior.

| Setting                                               | 0.2.0                | 0.3.0                                    |
| ----------------------------------------------------- | -------------------- | ---------------------------------------- |
| Base print width                                      | 120                  | Prettier default: 80                     |
| Data-format print width                               | 100                  | Prettier default: 80                     |
| Base indentation                                      | Tabs                 | Prettier default: two spaces             |
| JavaScript/TypeScript quotes, including embedded code | Prefer single quotes | Prettier default: prefer double quotes   |
| JSONC/JSON5 trailing commas                           | None                 | Prettier default: `all`                  |
| XML attribute quotes                                  | Double quotes        | Plugin default: preserve existing quotes |
| XML whitespace sensitivity                            | `preserve`           | Plugin default: `strict`                 |
| Astro/Svelte/TOML/XML parser selection                | Explicit overrides   | Filename inference by installed plugins  |

CSS, HTML, JSON, YAML, Markdown, and MDX continue to use spaces by default.
Markdown and MDX retain the default 80-column width. TOML quote preferences
now come from the plugin defaults rather than explicit `keyQuoteStyle` and
`stringQuoteStyle` settings.

XML's strict mode treats whitespace as significant, so markup can remain on
one line where 0.2.0 inserted structural line breaks. Set
`xmlWhitespaceSensitivity: "preserve"` explicitly if you need the previous
structural formatting behavior.

## Upgrade steps

1. Upgrade to `@cravingmaker/prettier-config@0.3.0`.
2. Run Prettier over your project and review the formatting diff, including
   embedded code and XML files.
3. Set any required formatting preferences explicitly in your own configuration.
   When extending `overrides`, retain the shared parser overrides first.

For example, this restores the previous base layout preferences and the XML
options. Other language-specific preferences can be added as further overrides:

```javascript
import config from "@cravingmaker/prettier-config";

export default {
  ...config,
  printWidth: 120,
  singleQuote: true,
  useTabs: true,
  overrides: [
    ...(config.overrides ?? []),
    {
      files: "**/*.xml",
      options: {
        printWidth: 100,
        useTabs: false,
        xmlQuoteAttributes: "double",
        xmlWhitespaceSensitivity: "preserve",
      },
    },
  ],
};
```

## Compatibility

- Requires Node.js **22.12.0 or newer** and Prettier **>=3.9.8 <4**.
- Optional plugin ranges remain Astro **>=0.14.1 <0.15**, Svelte
  **>=4.1.1 <5**, and Tailwind **>=0.8.1 <1**.
- The public import remains `@cravingmaker/prettier-config`, with `index.mjs`
  and `index.d.ts` published directly.
- TOML and XML plugins remain bundled; Astro, Svelte, and Tailwind remain optional.
