# Security policy

## Supported versions

Only the latest published release is supported for security fixes. Upgrade
older releases to receive fixes.

## Reporting a vulnerability

Report suspected vulnerabilities through
[GitHub's private vulnerability reporting form](https://github.com/cravingmaker/prettier-config/security/advisories/new).
Keep vulnerability details out of public issues and pull requests.

Please include:

- Affected package, Node.js, Prettier, and optional plugin versions.
- A minimal reproduction or proof of concept.
- Expected behavior, actual behavior, and potential impact.

For ordinary formatting bugs and feature requests, use
[GitHub issues](https://github.com/cravingmaker/prettier-config/issues).
